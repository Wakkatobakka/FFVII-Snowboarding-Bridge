# FFVII Snowboarding Bridge v0.1.2

First public release of FFVII Snowboarding Bridge.

This release moves the preserved Final Fantasy VII Snowboarding DoJa mobile game behind a clean local-import boundary: the public APK contains the Android bridge/runtime only, while users prepare their own compatible game data locally with the included Payload Builder.

## Verified on device

Samsung Galaxy S25 Ultra / Android 16:

- local payload import and verification
- 3D gameplay
- music/audio playback
- original phone keypad
- two-handed custom touch controls

## Release assets

- `FFVII_Snowboarding_Bridge_v0.1.2.apk` — signed Android bridge APK
- `FFVII_Snowboarding_Payload_Builder_v0.1.0.zip` — local Windows payload-preparation tool
- `FFVII_Snowboarding_Bridge_v0.1.2_Release_SHA256SUMS.txt` — SHA-256 checksums
- `FFVII_Snowboarding_Bridge_v0.1.2_Verification.txt` — release/device verification summary

No Final Fantasy VII Snowboarding game data is included.
